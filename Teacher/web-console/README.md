# Open Electronic Classroom · 机房控制面板（网页原型）

微机课机房教师端控制面板的前端原型。直接双击 `index.html`，或在当前目录启动任意静态文件服务器即可访问。
零依赖、无构建、不联网，铺满视口（无外边距、无滚动条），可直接内嵌到桌面程序。

## 界面结构

```
顶栏   品牌 / 机房 / 代理与异常 / 共享状态 / 上传下载 / 时钟
左侧栏 座位 · 分组管理 · 监看 · 列表 │ 白板 │ 设置
主舞台
  筛选条   排（全部/A/B）· 状态（全部/在线/异常/离线）· 搜索 · 全选/反选/清除
  标题行   视图名 · n / 12 台 · 状态图例
  操作条   屏幕共享 媒体共享 白板共享 │ 远程控制 远程指令 文件分发 文件收集 在线答题 │ 策略 … 目标
  内容区   监看墙 / 座位图 / 列表
右侧栏   管控（禁止USB传输、禁止联网、上网限制、访问限制策略）· 锁屏内容 + 一键锁屏 · 选中 · 操作日志
状态栏   机房 · 座位 · 在线 · 异常 · 离线 · 选中 · 投屏 · 教师机
```

## 机器模型

机房只认编号：每台机器就是 `机号 + IP + 排 + 状态`，没有学生姓名、没有登录。
状态只有四种：**在线 / 已锁定 / 异常 / 离线**。

- 改机号：在机器上右键 →「修改编号…」，输入新编号保存即生效（重名会被拦截），例如把 `PC-05` 改成 `B-05`

## 三种视图

| 视图 | 内容 |
| --- | --- |
| 监看墙（默认） | 12 路画面缩略：锁定显示「已锁定」，离线显示「无信号」，异常加琥珀边框与告警文案 |
| 座位图 | 机位卡片：状态灯 + 机号 + 使用者 + IPv4，选中加蓝框与勾 |
| 列表 | 表格：机号 / 使用者 / IPv4 / 状态 / 排，行可点选 |

## 操作条

一排集中所有设备操作。执行类动作（屏幕共享、关机、重启、网址）统一面向**全部在线机器**；针对单台机器的操作走右键菜单：

- **屏幕共享**：开关按钮，把**教师机整块屏幕**全屏推给全部在线机器。投送期间学生端与锁屏同理——画面被占满、键盘鼠标失效、不能切到其他页面，只能看；开启后按钮变红「停止共享」，顶栏显示「屏幕共享 · 教师机」
- **投学生机**：在某台机器上右键 →「投屏此机」，顶栏变成「屏幕共享 · PC-04」，日志记「学生机 PC-04」
- **媒体共享**：先弹窗选视频 / 音频 / 图片，点「投放」后才真正开始（按钮变红），同时自动停掉屏幕共享与白板共享；再点按钮即停止
- **白板共享**：开关态，与屏幕共享、媒体共享互斥。开启后左侧栏「白板」里画的笔迹实时同步给全部机器；未共享时只是本地画板，画稿不会丢
- **远程控制**：弹出机器列表，点一台即接管该机（离线机器置灰不可选）
- **远程指令**：弹窗里三个按钮——关机 / 重启 / 打开网址。点按钮进二次确认，确认后**对全部在线机器**下发；
  命令行的单机操作走右键菜单（见下）
- **文件分发 / 文件收集**：弹窗，标题栏显示目标范围；收集默认目录 `D:\课堂作业`
- **在线答题**：一键下发答题卡
- **策略**：打开「访问限制策略」弹窗，三选一：白名单（只放行列表内）/ 黑名单（只拦截列表内）/ 完全禁止（全拦）。
  选「完全禁止」时，除「限制方式」外的输入框、下拉、按钮、开关全部置灰且不可点击（切回白/黑名单即恢复）。
  黑白名单支持**预设**：下拉即套用、命名后「存为预设」、选中后可「删除」（**需点两次确认**，3 秒内不点自动取消），预设随策略一起保存
- 右键菜单仍保留：打开网址、启动程序、锁定屏幕、开机 / 关机 / 重启

## 其它交互

- 选择：单击选中；**按住 Ctrl 单击**加减选；**Shift 单击**连选一段；在空白处**按住左键拖拽框选**（Ctrl + 拖拽为追加）；空白处单击清空
- **一键锁屏**：按钮即开关。按下给目标机器下发锁屏——整屏变黑、屏蔽键盘鼠标（不是调用系统锁屏），
  屏幕上显示「锁屏显示内容」里自定义的文字；再按一次解除。锁屏期间机器状态显示为「已锁定」
- 右键：主机上右键弹出上下文菜单（投屏此机 / 远程控制 / **远程指令** / 锁定屏幕 / 打开网址 / 启动程序 / 重启 / 关机 / 开机 / 仅选此机）
- 白板：9 种颜色、2/4/8px 三档粗细（默认 4px 高亮）、橡皮、清空；右键菜单为撤销上一笔 / 清空画板；**清空需二次确认**（共享中会同步到后端）
- 右键「远程指令」打开**伪终端**：针对这一台机器执行命令，内置 `ipconfig` / `ping` / `dir` / `whoami` 的回显示例，其余命令只会提示"已下发"（演示用，不真正执行），作用对象是当前选中的机器；空白处右键为全选 / 反选 / 清除选择
- 全局禁止文本选中与图片拖拽（输入框内仍可正常选择、粘贴），右键不再出现浏览器默认菜单
- 双击主机打开独立的远程控制窗口（默认观看模式，工具栏「开始控制」才接管；窗口关闭即断开）
- 分组管理：新建 / 删除分组，卡片里列出该组机器，把机器标签拖进卡片即可归组；删除分组时组内机器转入未分组
- 监看墙按排分组（A 组 / B 组），组头带小三角与横线，点一下折叠或展开，组头右侧显示该组台数
- 排筛选、状态筛选、搜索（机号 / IP / 状态）组合过滤
- 全选 / 反选 / 清除作用于当前可见集合
- 右侧「范围」切到「选中」后，操作条的目标会跟着变（例如「选中 2 台」）
- 保存规则：**界面上直接看到的选项即时生效**（投屏范围、管控开关、锁屏、筛选、选择），不设保存按钮；
  **弹窗里的设置需要确认**（访问白名单、控制台设置），弹窗内改动只是草稿，点「保存」才生效并写日志，
  只有点「取消」才会关闭并整次丢弃（点遮罩、按 Esc 都不会关闭，避免误关丢草稿），重开回到上次保存的状态
- 所有操作写入右下角操作日志（时间 + 动作 + 目标，保留最近 80 条）

## 两种运行方式

- **双击 `index.html`**：纯前端演示，机器数据写死在 `app.js` 的 `MACHINES` 数组里，改动只存在内存中。
- **通过 `Teacher/server`（Python）打开**：页面检测到自己在 http(s) 下，会请求 `/api/state` 并把服务端作为唯一真相，
  同时订阅 `/api/events`（SSE）接收实时变更；所有操作命令走 `/api/command`。

## 说明

纯静态原型：设备数据写死在 `app.js` 的 `MACHINES` 数组里，交互只改前端状态，不连后端、不持久化。
接入真实机房时，把这套渲染换成设备发现 / 信令数据即可，视图与控制逻辑不需要动。
